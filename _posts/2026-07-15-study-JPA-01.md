### Entity
```jsx
import jakarta.persistence.*;
import lombok.*;

@Entity @Table(name = "tbl_product")
@Getter
@Setter
@NoArgsConstructor
@AllArgsConstructor
@Builder @ToString
public class ProductEntity extends BaseEntity {
    @Id //Primary Key
    @GeneratedValue(strategy = GenerationType.IDENTITY) //자동번호 생성기(Oracle:Sequence), auto increment
    private Long id;
    @Column(nullable = false, length = 100)
    private String productName;     // 상품명
    @Column(nullable = false)
    private Long price;             // 가격
    @Column(nullable = false)
    private int stock;              // 재고
    @Column(length = 50)
    private String category;        // 카테고리
}
```

#### @Entity

- JPA관리대상, Entity Manager가 관리한다
- DB table 생성됨
<br><br>

```jsx
import jakarta.persistence.*;
import lombok.*;
import org.hibernate.annotations.CreationTimestamp;

import java.time.LocalDateTime;

@Entity
@Table(name = "tbl_order")
@Getter @Setter @NoArgsConstructor @AllArgsConstructor
@Builder @ToString(exclude = "product")
public class OrderEntity extends BaseEntity {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    @Column(nullable = false)
    private int quantity;           // 주문 수량
    @Column(nullable = false)
    private Long totalPrice;        // 총 금액 (quantity × price)
    @Column(length = 20)
    @Builder.Default    //Builder 생성시 setting 없으면 default값
    private String status = "ORDERED";  // ORDERED / CANCELLED
    @CreationTimestamp
    @Column(updatable = false)
    private LocalDateTime orderDate;

    // ── @ManyToOne — 핵심 ─────────────────────
    // 주문(N) → 상품(1)
    // LAZY: 주문 조회 시 상품은 실제 사용할 때만 조회
    @ManyToOne(fetch = FetchType.LAZY)
    //@JoinColumn(name = "product_id", nullable = false) 
    //=>칼럼이름 똑같이 할 경우에는 생략 가능
    //=>참조된 쪽에 카럼이 생성된다. 칼럼의 이름은 field이름 + 상대 table의 키field이름
    private ProductEntity product;
}
```
#### @ManyToOne

- EAGER: 즉시 로딩 (default) -> 문제 발생:N(product)+1(order)
- LAZY: 지연로딩. 해당 엔티티를 조회할 때 연관된 테이블을 즉시 JOIN해서 가져오지 않음 
→ `@ToString`에는 연관 관계 필드도 포함되기 때문에 그냥 프린트 하면 오류남 
→ 해당 엔티티에 `@ToString(exclude = "연관관계필드명")` 추가

### Repository

**N+1문제**

쿼리를 1번 실행했는데 연관된 데이터를 가져오려고 불필요한 추가 쿼리가 N번 더 실행되는 현상
<br><br>

**N+1문제 해결**
- 방법1) 존재하는 함수를 재정의 (fetch join)
- 방법2) 개발자가 새로운 함수를 정의 (JPQL이용, fetch join 문장)
<br>
<br>

```jsx
import org.springframework.beans.factory.annotation.Qualifier;
import org.springframework.data.jpa.repository.EntityGraph;
import org.springframework.data.jpa.repository.JpaRepository;
import org.springframework.data.jpa.repository.Query;

import java.util.List;

public interface OrderRepository extends JpaRepository<OrderEntity, Long> {
    //N+1문제 해결
    //방법1
    @EntityGraph(attributePaths = "product")
    List<OrderEntity> findAll();

    //방법2
    @Query("select ord from OrderEntity ord join fetch ord.product")
    List<OrderEntity> findAll2();
    
    List<OrderEntity> findByProductId(Long id);
    List<OrderEntity> findByStatus(String status);
}
```

#### JPA 쿼리 생성 방법(2가지)

JPA는 엔티티 클래스 내부에 정의된 필드명을 기준으로 동작

```jsx
//방법1
find    By    ProductId  (Long id)
  |       |         |          |
[조회]  [조건]   [조회 조건필드] [매개변수 값]

//방법2
@Query(value = "SELECT * FROM order_table o WHERE o.product_id = :productId", nativeQuery = true)
List<OrderEntity> findByProductIdCustom(@Param("productId") Long productId);

SELECT *
FROM order_table o
WHERE o.product_id = 1;
```
- 방법1) Spring Data JPA ⇒ 메서드 이름 분석을 통한 쿼리 생성. 이름 규칙이 틀리면 에러
    - [행위/도입부] + [By] + [조건 필드/조건자]
    - 카멜 케이스, 매개변수 순서 맞추기, 복잡해지면 `@Query` 사용
<br>    
- 방법2) `@Query` 사용 ⇒ 직접 쿼리를 지정. 규칙을 따르지 않고 내가 원하는 메서드명을 쓰고 싶을 때
    - JPQL(nativeQuery = false 또는 생략): '엔티티 클래스'와 '필드명'을 기준으로 쿼리를 작성 (권장)
    - Native Query(nativeQuery = true): 실제 DB의 '테이블명'과 '컬럼명'을 기준으로 쿼리를 작성
<br><br>
<br>

#### Spring Data JPA 메서드 이름 규칙
- 공식문서: [https://docs.spring.io/spring-data/jpa/reference/jpa/query-methods.html](https://docs.spring.io/spring-data/jpa/reference/jpa/query-methods.html)
- 행위/도입부: find, read, get, query, search ==> SELECT으로 번역됨
- By: 조회할 조건(WHERE 절) 시작
- 일치/불일치: Equals, Not
- 대소 비교 (숫자, 날짜): LessThan, LessThanEqual, GreaterThan, GreaterThanEqual, Between
- 문자열 검색: Like, Containing, StartingWith, EndingWith
- NULL 조건 및 Boolean: IsNull, IsNotNull, True, False
- 다중 조건: AND, OR
- 정렬 및 개수 제한:OrderBy[필드명]Asc/Desc, First/Top[개수]

@SpringBootTest
public class Test2 {
    @Autowired
    ProductRepository proRepo;
    @Autowired
    OrderRepository orderRepo;

    @Test
    void f_insertProduct(){
        ProductEntity p1 = ProductEntity.builder()
                .productName("노트북A")
                .price(2_000_000L)
                .stock(100)
                .category("PC")
                .build();
        ProductEntity p2 = ProductEntity.builder()
                .productName("노트북B")
                .price(1_000_000L)
                .stock(100)
                .category("PC")
                .build();
        proRepo.save(p1);
        proRepo.save(p2);
    }

    @Test
    void f_insertOrder(){
        ProductEntity p1=proRepo.getReferenceById(1L);
        ProductEntity p2=proRepo.getReferenceById(2L);

        OrderEntity o1 = OrderEntity.builder()
                .quantity(5)
                .totalPrice(10_000_000L)
                .product(p1)
                .build();
        OrderEntity o2 = OrderEntity.builder()
                .quantity(10)
                .totalPrice(10_000_000L)
                .product(p2)
                .build();
        OrderEntity o3 = OrderEntity.builder()
                .quantity(2)
                .totalPrice(2_000_000L)
                .product(p2)
                .build();
        orderRepo.save(o1);
        orderRepo.save(o2);
        orderRepo.save(o3);
    }

    @Test
    void f_selectAllProduct(){
        //Product(1) <--- Order(N)
        //@OneToMany ---- @ManyToOne
        proRepo.findAll().forEach(p->{
            System.out.println(p);
        });
    }

    @Transactional
    @Test
    void f_selectAllOrder() {
        orderRepo.findAll2().forEach(o->{
            System.out.println(o);
            System.out.println(o.getProduct());
        });
    }

    @Test
    void f_lab(){
        proRepo.findByCategory("PC").forEach(p->{
            System.out.println(p);
        });
        System.out.println("===");
        proRepo.findByStockIsNotNull().forEach(p->{
            System.out.println(p);
        });
        System.out.println("===");
        proRepo.findByProductName("노트북A").forEach(p->{
            System.out.println(p);
        });
        System.out.println("===");
        orderRepo.findByProductId(1L).forEach(o->{
            System.out.println(o);
        });
        System.out.println("===");
        orderRepo.findByStatus("ordered").forEach(o->{
            System.out.println(o);
        });
    }

}
